# StageScout · SCG

Публичный радар проектов Астаны. Статический сайт: HTML, CSS и JavaScript без установки зависимостей. Все события и деловые контакты в events.json получены из публичных источников.

## GitHub Pages

1. Создайте публичный репозиторий StageScout-SCG и загрузите файлы этой папки в корень ветки main.
2. Settings → Pages → Deploy from a branch → main → /(root) → Save.
3. Дождитесь успешного Pages deployment. Сайт открывается по адресу, указанному GitHub Pages.

Все локальные ссылки и загрузка events.json работают в подпапке репозитория. .nojekyll отключает обработку Jekyll.

## Возможности

Поиск по событиям и организаторам; быстрые фильтры концертов и стендапов; направления Волонтёры, Staff, PR и Медиа; история источников; отдельные emailSource и phoneSource; личные стадии, заметки и черновики; экспорт/импорт; мобильная навигация.

## Данные и доступ

Это опубликованная копия ленты: дата исследования указана в интерфейсе. Обновление страницы перечитывает опубликованный events.json и само по себе не запускает веб-исследование. Для обновления публичной ленты нужно опубликовать новую версию этого файла.

Заметки, профиль, самостоятельно добавленные контакты и черновики каждого посетителя сохраняются только в localStorage его браузера. Сайт не отправляет сообщения автоматически. Общая очередь SCOUT / ECHO / CUE / CAST с D1 и персональными данными команды находится в отдельном защищённом командном центре. Она не скопирована в публичный репозиторий.

Анонс и контакты проверяются отдельно. Наличие email и телефона не доказывает участие организатора, доступность команды или подтверждённые задачи. Используйте приложенные первичные источники.

Исходный интерфейс и механизм экспорта поддерживаются в репозитории существующего StageScout Site.
